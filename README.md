# Agrinho-2026
Introdução

Este projeto tem como tema a relação entre a produção rural e a preservação ambiental, destacando a importância de equilibrar a produção de alimentos com o cuidado dos recursos naturais. A agricultura é essencial para a sociedade, pois fornece alimentos, gera empregos e contribui para a economia. No entanto, quando realizada sem responsabilidade, pode causar impactos ambientais como a degradação do solo, a poluição da água e a redução da biodiversidade.
Dessa forma, o projeto busca mostrar a importância da sustentabilidade no campo, apresentando como é possível produzir de forma eficiente e ao mesmo tempo preservar o meio ambiente, garantindo qualidade de vida para as futuras gerações.

 Como funciona o projeto

O projeto foi desenvolvido utilizando as linguagens de programação web HTML, CSS e JavaScript.
O HTML é responsável pela estrutura do site, organizando textos, títulos, botões e seções de conteúdo.
O CSS define todo o estilo visual da página, como cores, imagens de fundo, tamanhos, espaçamentos e layout, tornando o site mais bonito e organizado.
O JavaScript adiciona interatividade, permitindo que o usuário clique em botões como “Saiba Mais” e “Clique aqui para descobrir curiosidades”, exibindo informações adicionais de forma dinâmica.
Assim, o site se torna interativo, educativo e de fácil compreensão, ajudando na aprendizagem sobre o tema.

Créditos

Este projeto foi desenvolvido com fins educativos, utilizando apoio de ferramentas digitais para auxiliar na programação, organização e estruturação do site.
O conteúdo foi elaborado com foco no tema sustentabilidade na agricultura, e a construção do projeto contou com auxílio na parte técnica de desenvolvimento web (HTML, CSS e JavaScript).
